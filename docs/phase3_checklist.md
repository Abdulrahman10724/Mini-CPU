# Phase 3 checklist — console output with the parser

Same procedure as Phase 2: copy `tests/<name>.txt` to `program.txt`, run CPU.exe (DEBUG = 1)
and compare the whole console output. The top part (BYTES / LINES / `[...]`) is the same
as in Phase 2. The new part starts at `PARSED:`.

How to read a PARSED line: `OP` 1=MOV 2=ADD 3=SUB 4=CMP 5=INC 6=DEC 7=JMP 8=JZ 9=JNZ 10=HLT,
`DST` 0=AX 1=BX 2=CX 3=DX, `SRCTYPE` 0=none 1=register 2=number.
For SRCTYPE=1, SRC is a register index. For jumps, SRC is the target line.

Test 17 (no program.txt) still prints only `FILE MISSING`. DebugPrintParsed prints nothing.
